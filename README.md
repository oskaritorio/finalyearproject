## Disclaimer

MuseChum is a wellbeing support application and not a substitute for professional medical advice, diagnosis or treatment. The chatbot is rule-based and designed only for supportive reflection.


Features

- User authentication with bcrypt hashing
- Encrypted journal system
- Daily mood tracking
- Rule-based AI chatbot
- Crisis detection and support resources
- SWEMWBS + PHQ-2 wellbeing assessment
- GDPR-compliant data export and deletion
- Dockerized backend



Technologies Used

 ### Backend
- FastAPI
- SQLAlchemy
- SQLite
- Uvicorn
- bcrypt

### Frontend
- HTML
- CSS
- JavaScript

### Other Tools
- Docker
- Swagger UI
- spaCy




## Installation

### Clone Repository
git clone <repo-url>

### Backend Setup
cd backend
docker-compose up --build

### Frontend Setup
cd frontend
python -m http.server 3000
